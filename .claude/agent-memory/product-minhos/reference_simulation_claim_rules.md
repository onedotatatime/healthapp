Any new number or claim on the two simulation screens is bound by rules that are not in the code:

- The `CEO ·` comment on Linear MIN-4506 (2026-11-14): three conditions on the 20% assumption (always with "assume/assumption"; no study attached; drop shown at true size, axes from zero, "show the numbers large, not a cropped axis") and a scope line: any other use of the 20% "comes back first" to the CEO seat. A derived figure (for example euros) is such a use, so it is routed to the CEO seat, not to the founder.
- Six labels are fixed word for word by the CTO (MIN-4504): four in `src/features/simulate/copy.ts`, `simLabel` and `panelLabel` in `src/features/matches/copy.ts`.
- `data/synthetic/simulation.json` is generated by `scripts/synthetic/simulate.py` (Cron, MIN-4505). A new model value is a Backend sub-issue on the generator, never a hand edit of the JSON or a number in a component. The dashboard (MIN-4600) reads the same file, so changes are additive.
- Figures and wording of record: `docs/simulation-copy.md` (Anna, MIN-4506).

First applied on MIN-4603 (motion and the euro figure, 2026-11-15). Check the comment still stands before relying on it.
