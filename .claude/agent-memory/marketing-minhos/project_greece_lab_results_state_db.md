Since 2026-11-01 EOPYY labs must post results into one national database shown in MyHealth (Ta Nea 2026-11-02). Greek searches for moving/storing exams are below Google's floor; "myhealth app" 9,900/mo. Details: docs/research/treg-findings-2026-11-14.md (MIN-4469).

**Why:** the deck's "patients carry paper" angle is weaker for Greece; the gap left is private/out-of-pocket tests, imaging, older and foreign records, and the doctor-side summary.
**How to apply:** pitch healthapp on what the state file does not hold. In Greek copy never write "εξετάσεις" alone (Google reads school exams); say "ιατρικές εξετάσεις" or "αποτελέσματα εξετάσεων". treg note: DataForSEO bulk traffic needs a location_code; worldwide/US calls returned provider 500 (free).
