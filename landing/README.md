# healthapp landing

One-page showcase. Vite + React + Lenis + React Bits (copied in `src/components/`).

- Dev: `npm install && npm run dev` (http://localhost:5173)
- Build: `npm run build` (output in `dist/`)
- Images: drop `hero.webp`, `how-1.webp`, `how-2.webp`, `how-3.webp`, `og.png` into `public/img/`. Until then a calm placeholder block shows. Sizes and prompts: `docs/landing/design-spec.md`.
- Footer `[name]` and `[contact]` are placeholders in `src/App.tsx`.
